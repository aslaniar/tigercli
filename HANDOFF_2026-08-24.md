  first-draft gate passed against the broken code: one exercised the wrong
  path, one asserted against the State setter when the defect was the CALLER,
  and one "passed" only because the reverted code no longer COMPILED and the

  being corrupted.
- A BACKUP'S NAME IS NOT ITS CONTENTS. Hash it.
